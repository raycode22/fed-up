# Frequently Asked Questions

## Why is this a static site?
The project is designed to run with GitHub Pages and no backend. That keeps costs low and maintains privacy.

## Can I edit the YAML directly?
Yes. Add or update entries in `config/*.yaml`, then run `python build/build.py` to regenerate the static data.

## Does this work on Fedora 38?
The config is targeted at Fedora 39, 40 and 41. Older versions may require manual adjustments.
