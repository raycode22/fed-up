# SPEC_04: User Interface

## Primary flow
1. User lands on the page
2. Most items are preselected
3. User unchecks anything not desired
4. User clicks Download or Copy
5. Script is generated and saved locally

## UI details
- Clear visual separation between categories
- Compact item cards with labels and low-friction toggles
- Script preview area with monospace formatting
- Mobile responsive layout for narrower screens

## UX goals
- Fast, readable, and low-friction
- Works without a backend
- Relevant warnings and clear actions
