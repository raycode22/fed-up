Choose the tools and settings you need, then download a setup script to run on your Fedora machine.

Before you run a script

Fed-up only builds and downloads scripts; it does not run them. Read the generated commands before running anything with sudo. Cleanup and revert scripts can change installed packages, so review DNF's proposed changes and cancel if unsure.

Care for your Fedora system

Clean up package caches

Clear DNF caches and review DNF's proposal to remove unused dependencies. It may include packages unrelated to Fed-up, so cancel if unsure.

Undo Fed-up installs

Generate a review-before-removal rollback for RPM packages tracked by current Fed-up setup scripts. Earlier scripts did not create a package manifest. Repositories, settings, Flatpaks, and personal files are not changed.
