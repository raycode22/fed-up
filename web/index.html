Fed-up

System Setup Shell Script Builder for Fedora Linux

Choose the tools and settings you need, then download a setup script to run on your Fedora workstation.

Before you run a script

Fed-up only builds and downloads scripts; it does not run them. Read the generated commands before running anything with sudo. Cleanup and revert scripts can change installed packages, so review DNF's proposed changes and cancel if unsure.

After setup

System cleanup & revert

Generate a Fedora cache cleanup script or a review-before-removal rollback for RPM packages newly installed by current Fed-up setup scripts. Neither option removes personal files.

Cleanup runs dnf clean all and offers DNF's interactive autoremove proposal for your review; DNF may include dependencies unrelated to Fed-up, so cancel if unsure. Revert targets RPM packages tracked by current Fed-up setup scripts; earlier scripts did not create a revert manifest. Revert leaves repositories, system settings, Flatpaks, and user data unchanged.
