System cleanup & revert

Generate a Fedora cache cleanup script or a review-before-removal rollback for RPM packages newly installed by current Fed-up setup scripts. Neither option removes personal files.

Cleanup runs dnf clean all and offers DNF's interactive autoremove proposal for your review; DNF may include dependencies unrelated to Fed-up, so cancel if unsure. Revert only targets tracked RPM packages; Earlier setup scripts did not create a revert manifest. Revert leaves repositories, system settings, Flatpaks, and user data unchanged.
