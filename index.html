How to use Fed-up

  1. Select the Fedora release and desktop environment.
  2. Choose options and provide any requested values.
  3. Review the complete install or revert script and its warnings.
  4. Copy or download the script. It runs only if you choose to run it yourself.

About and privacy

  • This static site has no analytics or tracking, and does not send your selections or preferences anywhere. It uses no cookies; theme, text size, and selections are stored locally in your browser where storage is available.
  • The website never runs commands. It generates scripts for you to inspect, copy, download, and run yourself.
  • The generated script may install python3, Fedora's optional gum text UI, and flatpak when selected items require it, plus your chosen software. Python packages are not installed with pip. gum is optional and is never installed from a third-party repository by this generator.
  • Software sources and any non-reversible operations are identified in the generated script. Review it before running; system changes require administrator privileges.
  • Source code is available under the MIT License.
  • This is an independent, unofficial project and is not affiliated with or endorsed by the Fedora Project or Red Hat. Provided as is.
