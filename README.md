# Fed-up

Fed-up is an unofficial Fedora setup script generator. Build a personalized setup from a curated catalog of apps and system options, then review and download the generated scripts.

Choose a Fedora release and desktop, browse categories from development tools to media and gaming, and see each action's risks and reversibility before you use it. Fed-up runs in your browser and never executes commands on your computer.

This is a static project with no backend or build step. Open [`index.html`](./index.html) to use it.

Fed-up is independent and is not affiliated with or endorsed by the Fedora Project or Red Hat. Licensed under MIT.
